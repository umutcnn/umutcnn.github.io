## Recruiter path (brief §16)

Who / what / TEKNOFEST / projects / education / CV / contact are all reachable without waiting for animations:
the hero shows role, TEKNOFEST 2nd place and the CTAs in the first screen; About holds education; a **CV link is now
in the desktop navbar** (mobile already had it in the menu); contact links are plain anchors.

## Comparison with the reference site

| Criterion            | Reference                                         | This site                                                                             | Note                                                                                           |
| -------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Typography           | Large condensed grotesque, lowercase nav          | Space Grotesk display + Inter + JetBrains Mono labels                                 | Comparable quality; this site's mono "instrument" labels give it a distinct engineering voice. |
| Scroll transitions   | Section colour washes, full-bleed device mock-ups | Paper ↔ night tone changes, clip-path reveal into the pinned Work panel               | Both cinematic; this site keeps content readable without JS.                                   |
| Project storytelling | Product mock-ups                                  | Generated, honest "conceptual" visuals + full case studies with limits                | Stronger technical depth; fewer real screenshots because most work is confidential.            |
| Motion rhythm        | Few, large moves                                  | Reveal + kinetic name + pinned work                                                   | V4 fixed the reveal system that had effectively switched itself off after 3.5 s.               |
| Mobile composition   | Simple stack                                      | Dedicated touch layouts (clusters instead of graph, list instead of zoomable diagram) | Good; V4 added overflow cues to tab strips.                                                    |

## Deliberately not changed

- No redesign of the visual identity, palette or type scale — the existing system is consistent and already premium.
- No new heavy effects: the brief asks for motion restraint, and the hero is already the most animated screen.
- No invented content: MAKS ERP results and missing TEKNOFEST 2023 metrics stay absent (listed for the owner).
